# Constitution

## What This Is

dbl-vlog implements the append-only event stream V for DBL.

## Governing Principles

1. **V is append-only and immutable.**
2. **Only DECISION events are authoritative.**
3. **Observational fields excluded from digests.**
4. **Contracts win.** If code and contracts diverge, contracts are authoritative.

## What This Is Not

- Not a governance or boundary layer.
- Not an execution system.
- Not a persistence backend.
